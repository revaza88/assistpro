# AssistPro / ასისტი

React/Vite/TypeScript და Express საიტი revaza88/assistpro რეპოზიტორიაში.
დადასტურებული კონტაქტი: **info@assist.ge** — ბიზნეს ცენტრი კრწანისი მოდერნი,
გორგასლის №61. საჯარო დომენი და ჰოსტინგი ჯერ ასარჩევი/დასადასტურებელია.

## გაშვება და შემოწმება

Node.js 24+ და npm 9+:

```sh
npm ci --include=dev
npm run dev
npm run check
npm test
npm run build
npm start
```

`npm run dev` იყენებს Vite-ს და ლოკალურ საცდელ მიღებას. `npm start` უშვებს
წინასწარ აწყობილ production სერვერს. გარემოს ცვლადები ავტომატურად `.env`-დან
არ იტვირთება; გამოიყენეთ ჰოსტინგის გარემო, Compose ან Node-ის `--env-file`.
ბილდი მოიცავს `dist/index.js`, `dist/public` და `dist/prerender` საქაღალდეებს.

## ფუნქციები და მიმდინარე საზღვრები

- ქართულ/ინგლისურ/რუსულ ენებზე მობილური საიტი და სერვისების გვერდები.
- ინდუსტრიისა და რამდენიმე მომსახურების არჩევა, კონტექსტის შენარჩუნებით.
- ფასის მკაფიოდ მონიშნული დემო კალკულატორი; მოქმედი ტარიფი არ არის.
- FAQ, წინასწარ გენერირებული HTML და კონფიგურირებადი SEO.
- `INTAKE_MODE=disabled` production-ში გამორთავს ონლაინ მიღებას და სთავაზობს
  info@assist.ge-ზე დაკავშირებას. `INTAKE_MODE=local` მხოლოდ ცალკე ლოკალური
  ტესტისთვისაა: ერთი პროცესის JSON საცავი; არა production ბაზა ან CRM.
- ბაზა, რეალური შეტყობინებები, CMS, პორტალი და საჯარო ინდექსაცია არ გააქტიურებულა.

## განთავსება

სრული ნაბიჯები და დომენის/ჰოსტინგის/ინდექსაციის დარჩენილი საკითხები:
[docs/RELEASE.md](docs/RELEASE.md).

მომზადებულია Dockerfile, Compose, PM2 ალტერნატივა, Nginx შაბლონი და
`.env.production.example`. რეალური დომენის/სერვერის გარეშე deploy არ შესრულებულა.
`INDEXING_ENABLED=false` დატოვეთ staging-სა და შემოწმების პერიოდში.
