# საიტის სისტემური ტესტირება

2026-11-18. მოცულობა: მოქმედი React/Vite/Express პროექტი, სრული ბრენდული ინტეგრაციის შემდეგ.

## გეგმა

1. TypeScript და არსებული unit/regression ტესტები; production ბილდი.
2. ფუნქციური გზები: არჩევანი, URL/refresh/back, კალკულატორის საზღვრები,
   მოთხოვნაში კონტექსტისა და პირადი მონახაზის შენარჩუნება.
3. იზოლირებული loopback intake: ცარიელი/არასწორი ფორმა, პირველი შეცდომის ფოკუსი,
   წარმატება, API failure/retry, ორმაგი დაჭერა და დროებითი ფაილის ჩანაწერები.
4. ყველა საჯარო გვერდის ბმულები, ენები, 320–1440px, ღია/მუქი თემა,
   კლავიატურა, axe, 200% ტექსტი, JavaScript-ის/საცავის მიუწვდომლობა და ნელი ჩატვირთვა.
5. HTTP/API: არასწორი JSON, სტატუსები, საზღვრები, გაუთვალისწინებელი გზები,
   CSP nonce, ქეში, disabled intake, რეალური health კონფიგურაცია.
6. აღმოჩენილი ხარვეზების გასწორება, მიზნობრივი regression ტესტები, საბოლოო
   build/smoke/browser/Lighthouse და ცნობილი შეზღუდვების აღწერა.

მოქმედი საჯარო intake და მონაცემთა ბაზა არ აქტიურდება. საცდელი მონაცემები
`.artifacts/`-ში ინახება. მიმდინარე 5011 preview ტესტების შემდეგ განახლდება.

შემოწმებები; ეს არ ნიშნავს ყველა შესაძლო მდგომარეობის ან მომავალი ინტეგრაციის

### გავლილი შემოწმებები

  ახალი ტესტები: რეალური HTTP feature flags, არასწორი JSON/500/413,
  მონაცემების დაფარვა, ვაკანსიის ვალიდაცია, 101-ე API მოთხოვნის 429 და
  ძველი ჩანაწერების თავსებადობა. ტესტის სერვერები დროებით loopback პორტებს იყენებს.
- **120 Chrome გვერდი/ზომა/თემა**: 15 გვერდი × 320/390/768/1440px ×
  light/dark. გადაცდენა და კონსოლის/გვერდის შეცდომები: 0. ლოგოს ბაიტები,
  თანაფარდობა და სლოგანი შენარჩუნებულია.
- **18 Microsoft Edge გვერდი/ზომა**: 6 ძირითადი გვერდი × 320/768/1440px;
  მენიუს კლავიატურა, მუქი თემა და hover დამატებით. Page errors: 0.
- **30 ინგლისური/რუსული გვერდი**: სათაურები, ენა, გადაცდენა და ყველა მოძიებული
  შიდა ბმულის HTTP სტატუსი. გაუმართავი შიდა ბმულები: 0.
- **axe — 30 გვერდი/თემა**: WCAG 2 A/AA, 2.1 A/AA და best-practice
  წესები. საბოლოო შედეგი: 0 აღმოჩენილი დარღვევა. ზოგიერთ რთულ/გრადიენტულ
  ელემენტზე `incomplete` პასუხი რჩება; ის ავტომატურად გავლილად არ ითვლება.
- **JavaScript-ის გარეშე**: 15 base გვერდი, 320px და სისტემური dark —
  სათაური, გადაცდენა და რეალური CSS ფერების კონტრასტი; ეკრანის სურათი დათვალიერებულია.

- **ფორმა იზოლირებულ local intake-ზე**: ცარიელი submit → პირველი ველის ფოკუსი;
  არასწორი არხი → ველის შეცდომა; გამიზნული 500 → მონაცემები შენარჩუნდა;
  შემდეგი რეალური POST → 201 და მონახაზის გასუფთავება. რეალური ელფოსტა არ გაგზავნილა.
- **მონახაზი და არჩევანი**: პირადი ტექსტი/თანხმობა შენარჩუნდა არჩევანისა და
  კალკულატორის რედაქტირებისას; პირადი მონაცემები URL-ში არ გადავიდა.
  მიმდინარე მოთხოვნისას განმეორებითი submit მხოლოდ ერთ fetch-ს ქმნის.
- **კალკულატორი**: -1, წილადი, ცარიელი მნიშვნელობა და ზღვარს გადაცდენა

  recovery რეჟიმი რიცხვით ფასს არ აცხადებს. არასწორი გაზიარებული ბმულები
  ხილულ შეცდომას აჩვენებს და მოთხოვნას ვერ აგზავნის.
- **მდგრადობა**: blocked localStorage-ისას ენა/თემა მუშაობს;
  წარუმატებელი ენის chunk-ისას ქართული რჩება და შეცდომა ცხადდება;

  სამ გვერდზე hydration შეცდომას არ ქმნის.

  unsafe-inline/eval-ის არქონა; framing შეზღუდვა; hashed asset immutable cache
  და raw HTTP conditional 304; HEAD-ის ცარიელი სხეული; 404 გზები/აქტივები;
