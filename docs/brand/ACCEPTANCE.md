# ASSIST 2.2 — საიტის მიღების კრიტერიუმები

**ეს არის კრიტერიუმების სია, არა შესრულებული ტესტების ანგარიში.** ამ რეპოზიტორიაში ფაქტობრივი შედეგები, გარემო და შეზღუდვები წერია [IMPLEMENTATION_ACCEPTANCE.md](IMPLEMENTATION_ACCEPTANCE.md)-ში. 18 ნოემბრის ისტორიული QA ახალ შემოწმებად არ ითვლება.

## წყარო და ლოგო

- [ ] მიმდინარე რეპოზიტორია, განშტოება, საწყისი commit და განსახილველი ცვლილება ზუსტად არის დაფიქსირებული.
- [ ] `BrandLogo` იყენებს სრულ 1405 × 235 PNG-ს; საჯარო ფაილი ემთხვევა წყაროს SHA-256-ს.
- [ ] ხილული A/I, ქართული წარწერა, divider, პიქსელები და პროპორციები უცვლელია; არ არის crop, filter, blend ან ახალი მონოგრამა.
- [ ] ლოგო დგას უშუალოდ `#FDFDFD` ბრენდულ ზოლზე, მუდმივი ჩარჩოს/ბარათის/ჩრდილის გარეშე; keyboard focus შენარჩუნებულია.
- [ ] სლოგანი ზუსტად არის „თქვენი ბიზნესის მხარდამჭერი“, ცოცხალი ტექსტით და საჭირო `lang="ka"`-ით.
- [ ] ლოგოსა და სლოგანის ქვემოთ ძველი მომსახურებების ხაზი არ დაბრუნებულა; ჩვეულებრივი სერვისები შენარჩუნებულია.
- [ ] არსებული სრული-PNG favicon უცვლელია; კომპაქტური ხატულის წაკითხვადობის შეზღუდვა აღწერილია და ახალი ვარიანტი არ შექმნილა.

## ინტერფეისი და ხელმისაწვდომობა

- [ ] ღია UI როლები ემთხვევა 2.2 საცნობარო მნიშვნელობებს; runtime-ს ერთი სემანტიკური წყარო აქვს.
- [ ] მუქი კონტენტის ადაპტაცია აღრიცხულია და ცალკე შემოწმებულია; header/footer-ის ლოგოს გარემო ორივე თემაში ღიაა.
- [ ] Noto Sans Georgian და Noto Sans 400/700 ჩატვირთულია ლოკალურად, შესაბამისი glyph-ებითა და OFL ტექსტით.
- [ ] 320/390/768/1440 CSS px-ზე და რეალური breakpoint-ის ორივე მხარეს ტექსტი და ლოგო იკითხება; ჰორიზონტალური გადაცდენა არ არის.
- [ ] შემოწმებულია portrait/landscape ან ზუსტად არის მითითებული რომელი ორიენტაცია არ შემოწმებულა.
- [ ] Tab/Shift+Tab, Enter/Space და Escape მუშაობს მენიუში; ფოკუსი სწორად ბრუნდება და ყოველთვის ჩანს.
- [ ] normal/hover/pressed/focus/disabled/loading მდგომარეობები განსხვავდება; პირველადი ველები/ღილაკები 48 px წესს იცავს.
- [ ] კონტრასტის ფაქტობრივი წყვილები შემოწმებულია, მათ შორის კონტროლის საზღვარი, ფოკუსი და მდგომარეობები.
- [ ] ფორმის label და ტექსტური შეცდომები პროგრამულად არის დაკავშირებული; შეცდომა მხოლოდ ფერით არ აღინიშნება.
- [ ] 200% ტექსტი, 320px reflow, ტექსტის დაშორება და reduced motion შემოწმებულია ან ზუსტი შეზღუდვაა დაფიქსირებული.
- [ ] ბრაუზერის/მოწყობილობის რეალური სახელი და ვერსია მითითებულია. სტატიკური კოდის ანალიზი browser/device ტესტად არ ითვლება.

## ფუნქციები, უსაფრთხოება და გაშვება

- [ ] არსებული მარშრუტები, ნავიგაციის მიზნები, სერვისები და ავტორიზებული კომპანიის მონაცემები შენარჩუნებულია.
- [ ] ინდუსტრია/მრავალი მომსახურება → კალკულატორი → მოთხოვნა ინარჩუნებს კონტექსტს და პირადი ინფორმაციის მონახაზს.
- [ ] KA/EN/RU გადართვა და ენების მოთხოვნისას ჩატვირთვა შენარჩუნებულია; ქართული prerender მუშაობს.
- [ ] გამორთული production intake მართებულად არის განმარტებული და API უცვლელ კონტროლს ინარჩუნებს.
- [ ] ლოკალური ვალიდაცია/შეცდომა/ხელახალი ცდა, საჭიროებისამებრ, რეალურად არის შემოწმებული; დემო შენახვა ნამდვილ მიწოდებად არ ცხადდება.
- [ ] CSP, noindex და უცნობი `SITE_URL`-ის არსებული პოლიტიკა შენარჩუნებულია.
- [ ] `npm run check`, `npm test`, `npm run build` დასრულებულია; ჩავარდნას ახლავს ფაქტობრივი მიზეზი და ზემოქმედება.
- [ ] საჭირო API/HTTP/browser შემოწმება ჩატარებულია ან კონკრეტული ტექნიკური შეზღუდვა წერია.
- [ ] Git commit/PR და საჯარო განთავსება ცალკე არის აღრიცხული. PR ან ლოკალური გაშვება deployment არ არის.

## შემდეგი დიზაინერული ცვლილება

მიღების ჩანაწერში უნდა ჩანდეს მოთხოვნის წყარო და თარიღი, კონკრეტული ცვლილება, რეალური მტკიცებულება და დარჩენილი საკითხი. უკვე ავტორიზებული სამუშაო თავიდან თანხმობას არ საჭიროებს. ახალი ლოგო/ხატულის ვარიანტი ცალკე კონკრეტულ მოთხოვნას ეყრდნობა. შემოწმება არ ნიშნავს WCAG სერტიფიცირებას ან ყველა არხის საწარმოო მიღებას.
