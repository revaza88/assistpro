**ზუსტი სლოგანი: „თქვენი ბიზნესის მხარდამჭერი“.** იგი ცოცხალი HTML ტექსტია, შეიძლება გადაიტანოს სტრიქონზე და არ უნდა ჩაიხატოს PNG-ში. - მოკლე გადასვლა 150 ms; `prefers-reduced-motion` გამორთავს არასავალდებულო მოძრაობას. Loading მოქმედება განმეორებით დაჭერას ბლოკავს; შეცდომა ყოველთვის ტექსტითაც იწერება.

პაკეტის 1100/760/420/359 px ზღვრები საცნობარო HTML-ის გადაწყვეტაა. არსებული პროექტის განლაგებას ავტომატურად არ ჩაენაცვლოს; შემოწმდეს რეალური breakpoint-ის ორივე მხარე. ნიმუშის ერთგვერდიანი ბმულები და გლობალური CSS არ ანაცვლებს საიტის არსებულ მარშრუტებსა და theme-ს.

## 6. ცვლილების კონტროლი

შემდგომ დიზაინერულ ცვლილებას ჰქონდეს კონკრეტული მოთხოვნა, მიზანი, შესაცვლელი ელემენტები, გავლენის ფარგლები და შემოწმების შედეგი. ეს წესი უკვე ავტორიზებული დავალების ჩვეულებრივ ტექნიკურ შესწორებას თავიდან თანხმობას არ სთხოვს. ახალი ლოგოს ვერსია ცალკე მოთხოვნაა.
