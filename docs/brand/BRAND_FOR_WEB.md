### 4.1. მიმდინარე მობილური header

წყაროებია [`navigation.tsx`](../../client/src/components/navigation.tsx) და [`index.css`](../../client/src/index.css). PR #5-ის მოქმედი წესებია:

- Header რჩება `sticky top-0`. კომპაქტურ განლაგებაში სრული ლოგო მარცხნივაა, ენის არჩევანი და მენიუს ღილაკი — მარჯვნივ; grid არის `minmax(0, 1fr) auto`.
- კომპაქტური წესები მოქმედებს `@container assist-header (max-width: 72em)`-ზე. დესკტოპის ნავიგაცია ირთვება `@media (min-width: 90em)`-ზე, თუმცა კონტეინერის წესი შეიძლება კვლავ კომპაქტურ განლაგებას მოითხოვდეს. ეს ზღვრები ფიქსირებულ მობილურ px breakpoint-ად არ ითარგმნოს.
- ლოგოს კონტეინერის სიგანეა `min(13.75rem, 100%)`; სურათი ავსებს მას, ინარჩუნებს `1405 / 235` პროპორციას და `height: auto`-ს. 16 px root-ისას 220 px ზედა ზღვარია; ლოგო საჭიროებისას დარჩენილ სივრცემდე პროპორციულად მცირდება.
- ენის კონტროლი და მენიუს ღილაკი მინიმუმ `3rem × 3rem`-ია (16 px root-ისას 48 × 48 px). კომპაქტურად ჩანს `KA` / `EN` / `RU`; native select-ში სრული სახელები და ხელმისაწვდომი label შენარჩუნებულია.
- `@container assist-header (max-width: 15em)` განზრახ ქმნის ორ რიგს, კონტროლების მარჯვნივ გასწორებით. გაზრდილი ტექსტისას ლოგო და კონტროლები ერთ რიგში ძალით არ მოთავსდეს.
- გახსნილი მენიუ სქროლვადია და viewport-ის სიმაღლეს ითვალისწინებს. შენარჩუნდეს `aria-expanded`, `aria-controls`, Escape-ით დახურვა და ტრიგერზე ფოკუსის დაბრუნება.
- Header-ში დამატებითი სლოგანი არ ჩაისვას; footer-ში არსებული სლოგანი რჩება ცოცხალ ქართულ ტექსტად.

[19 ნოემბრის მობილური header-ის ანგარიში](qa/2026-11-19-mobile-header/README.md) ინახავს იმდროინდელ 320/390 px ხედებსა და იზოლირებულ 200% ტექსტის შემოწმებას. ეს არსებული მტკიცებულებაა და ამ დოკუმენტაციის ცვლილებით ახლად ჩატარებულ browser ტესტად არ ჩაითვლება.
