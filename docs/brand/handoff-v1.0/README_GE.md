# ASSIST ბრენდბუქის გადაცემა Codex-ისთვის

პაკეტის ვერსია: 1.0. მომზადებულია 18 ნოემბერს, 2026, Asia/Tbilisi.
ლოგოს საფუძველი: ორიგინალი Master V1.2. ეს ორი ვერსია სხვადასხვა რამეს აღნიშნავს.

ეს პაკეტი აძლევს მიმდინარე საიტის პროექტს ბრენდის წესების ადგილობრივ, ვერსიონირებად ასლს. მასში არის მოქმედი გადაწყვეტილებები, ციფრული სახელმძღვანელოს მონაცემები, უცვლელი საცნობარო PDF და ლოგოს არსებული PNG ექსპორტი. საიტის კონკრეტული რეპოზიტორია არ შემოწმებულა და ეს პაკეტი მასში ჯერ არ არის შეტანილი.

## გამოყენება

1. გახსენით Codex-ის ის პროექტი და ჩატი, სადაც საიტზე უკვე მუშაობთ. პაკეტი მიუთითეთ ამავე გარემოში: დაურთეთ ხელმისაწვდომი ფაილების მიმაგრების ფუნქციით, ან შეინახეთ ადგილობრივად და მიუთითეთ მისი სრული მისამართი. თუ ZIP-ის მიმაგრება არ არის ხელმისაწვდომი, გაშალეთ იგი და მიუთითეთ საქაღალდე.
2. Codex-ს გაუგზავნეთ `CODEX_PROMPT_GE.txt`-ის ტექსტი. ჯერ წაიკითხოს ეს README და `docs/brand/BRAND_FOR_WEB.md`.
3. `docs/brand/` გადაიტანოს საიტის პროექტის შესაბამის დოკუმენტაციის საქაღალდეში. თუ ამავე სახელის ფაილები უკვე არსებობს, შეადაროს შინაარსი და შეაერთოს საჭირო ცვლილებები, შენახული სამუშაოს გადაწერის გარეშე.
4. `AGENTS_SNIPPET.md`-ის მონიშნული სექცია დაამატოს პროექტის მოქმედ ინსტრუქციებს. არსებული `AGENTS.md` მთლიანად არ ჩაანაცვლოს. თუ მოქმედი `AGENTS.override.md` არსებობს, შეამოწმოს რომელი ფაილი იტვირთება და ბრენდის წესიც ხელმისაწვდომი გახადოს იმავე ჯაჭვში.
5. მიმდინარე საუბარში პირდაპირ წაიკითხოს დამატებული ინსტრუქციები და ბრენდის ფაილები. უკვე გაშვებულ Codex სესიაში მხოლოდ ფაილის შექმნით ავტომატურ გადატვირთვას ნუ ჩათვლით შესრულებულად. საჭიროების შემთხვევაში ახალ სესიაში გადაამოწმეთ მოქმედი ინსტრუქციების ჩამონათვალი.
6. მიღების დასადასტურებლად ჩამოთვალოს წაკითხული ფაილები, სწორად გაიმეოროს მოქმედი სლოგანი და უცვლელი ლოგოს წესი, და საიტის არსებულ კოდში შეადგინოს შესაბამისობის მოკლე ანგარიში.

Cloud გარემოში ფაილები უნდა მოხვდეს იმ რეპოზიტორიაში ან სამუშაო ასლში, საიდანაც შესაბამისი დავალება მუშაობს. მხოლოდ სხვა კომპიუტერის ლოკალურ საქაღალდეში მათი შენახვა ამ სამუშაო ასლს არ განაახლებს. Git-ის გამოყენებისას ეს დოკუმენტები დაექვემდებაროს პროექტის ჩვეულებრივ ვერსიების კონტროლს.

## მთავარი მიმდინარე წესი

გამოიყენება მხოლოდ სლოგანი **„თქვენი ბიზნესის მხარდამჭერი“**. სლოგანის ქვემოთ მომსახურებების ჩამონათვალი ამ ეტაპზე აღარ განთავსდება. კომპანიის სერვისების ცალკე ვებგვერდი ან განყოფილება ამ გადაწყვეტილებით არ უქმდება.

ლოგოს პრიალა ლენტისებრი A, ინდივიდუალური იასამნისფერი I, მუქი ლურჯი წარწერა და ქართული „ასისტი“ უცვლელია. ლოგოს ახალი ვარიანტის შექმნა ამ პაკეტის მიზანი არ არის.

## განახლების წესი

ბრენდის ახალი კონკრეტული მოთხოვნისას განახლდეს `BRAND_FOR_WEB.md`-ის გადაწყვეტილების ჩანაწერი; საჭიროების მიხედვით განახლდეს tokens/manifest და პროექტის ცვლილების აღწერაში მიეთითოს მიზეზი. შემდეგ Codex-მა მიმდინარე საუბარშიც წაიკითხოს შეცვლილი ფაილები. Space-ის ბმული წყაროს ადგილია; ავტომატური სინქრონიზაცია ამ პაკეტით არ შექმნილა.
