## აღმოჩენილი ქართული ტექსტის გენერაციის ხარვეზი

16 წინასწარ გენერირებულ გვერდში React 18-ის Node development renderer-ის
ნაკადის 2048-ბაიტიან საზღვრებთან ნულოვანი padding აღმოჩნდა. ერთ შემთხვევაში
footer-ის სლოგანიც გაწყდა. მხოლოდ ტექსტის შეცვლით ეს პრობლემა ვერ მოგვარდებოდა.

`entry-prerender.tsx` ახლა build-ისას იყენებს იმავე React ვერსიის Web Streams
renderer-ს (`react-dom/server.browser`), ელოდება `allReady`-ს და საბოლოო HTML-ს
კითხულობს `Response.text()`-ით. არსებული ტიპებისთვის დაემატა შესაბამისი subpath
დეკლარაცია. პაკეტები არ განახლებულა; runtime Express არქიტექტურა უცვლელია.
`scripts/prerender.ts` ბილდს აჩერებს NUL-ის ან ზუსტი footer-სლოგანის არყოფნისას.
