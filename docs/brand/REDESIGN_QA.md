## შრიფტების მიწოდება

Montserrat-ის ორი WOFF2 subset (Latin/Cyrillic), 400–700, მიღებულია ოფიციალური
[Google Fonts CSS endpoint-იდან](https://fonts.googleapis.com/css2?family=Montserrat:wght@400..700&display=swap).
ფაილები ინახება `client/public/assets/fonts/montserrat-*.woff2`-ში.
[SIL OFL ლიცენზიის წყარო](https://github.com/google/fonts/blob/main/ofl/montserrat/OFL.txt)
გადმოტანილია `Montserrat-OFL.txt`-ში. წყაროს WOFF2 ბაიტები არ შეცვლილა.
ბრაუზერი გარე Google Fonts მოთხოვნას არ აგზავნის. Georgian subset-ის preload
შენარჩუნებულია; Montserrat unicode-range-ით მხოლოდ საჭირო სიმბოლოებისთვის
იტვირთება. `font-display: swap` ბრენდის შრიფტის საბოლოო გამოჩენას უზრუნველყოფს.
Noto Serif მხოლოდ დროებით უცვლელ wordmark-ს ემსახურება.

Google Modern Web Guidance-ის `color`, `typography` და
`visually-stable-mixed-fonts` გამოყენებულია. კონტრასტი, rem ზომები, გადატანა,
მომხმარებლის თემა, forced colors და reduced motion შენარჩუნებულია.
`font-size-adjust: from-font` feature detection-ით გამოიყენება; ძველ ბრაუზერში
ბუნებრივი შრიფტი და 1.75 line-height რჩება.
