# ASSIST — საიტის ტექსტი და კომუნიკაციის ხმა

**ვერსია:** 2.2 · **სტატუსი:** დადასტურებული წესები და ცალკე მონიშნული სარედაქციო წინადადებები.

ეს მოკლე ჩანაწერი ეყრდნობა [2.2 პაკეტის](https://chatgpt.com/library?file_id=libfile_d93c9e088be88191a8a7edf819053fa5&account_id=personal) `docs/BRAND_CORE_AND_VOICE.md`-ს. არსებული დამოწმებული საიტის ტექსტი მხოლოდ ახალი მაგალითის მოსათავსებლად არ იცვლება.

## დადასტურებული

- სლოგანია **„თქვენი ბიზნესის მხარდამჭერი“**. სიტყვები და მიმდევრობა უცვლელია; სტრიქონზე გადატანა შეიძლება.
- სლოგანის ან ლოგოს ქვემოთ მომსახურებების სტრიქონი აღარ გამოიყენება. ფაქტობრივ მომსახურებებზე ჩვეულებრივი გვერდები და აღწერები დასაშვებია.
- არსებული იურიდიული და საკონტაქტო მონაცემების წყაროა `client/src/lib/company.ts`, რეპოზიტორიაში დაფიქსირებული ავტორიზაციით. დაუზუსტებელი ტელეფონი, პიროვნება, კვალიფიკაცია, კლიენტების რაოდენობა ან ფასი არ დაემატოს.
- სლოგანის EN/RU თარგმანი დამტკიცებული არ არის. ინგლისურ/რუსულ ინტერფეისშიც ქართული სლოგანი რჩება `lang="ka"`-ით.

## შემოთავაზებული ხმა

მშვიდი, პირდაპირი და ყურადღებიანი პროფესიონალი. ადამიანს მივმართავთ „თქვენ“-ით; ვამბობთ რას ვაკეთებთ, რატომ გვჭირდება ინფორმაცია და რა არის შემდეგი ნაბიჯი. რთულ ტერმინს ვხსნით იქ, სადაც ეს ადამიანს გადაწყვეტილებაში ეხმარება.

ტექსტური წერის სამუშაო წესია **ASSIST** და **ასისტი**; საჭიროებისას — „ASSIST (ასისტი)“. ეს წესი გრაფიკულ ლოგოს არ ცვლის. იურიდიული დასახელება ზუსტად აიღეთ გადამოწმებული წყაროდან.

არ გამოიყენოთ „100% გარანტია“, „ყოველთვის“, „საუკეთესო“, პასუხის დაუდასტურებელი ვადა ან გამოგონილი შედეგები. ახალი შეფასება, სტატისტიკა, პარტნიორის ლოგო და მომხმარებლის ციტატა მოითხოვს რეალურ წყაროსა და გამოყენების საფუძველს.

მობილურზე ტექსტის შემცირებისას არ გაქრეს არსებითი პირობა, ფასი/გამონაკლისი, დემოს სტატუსი ან შემდეგი ნაბიჯი. ხელმისაწვდომი სახელები, მუდმივი label-ები და ტექსტური შეცდომები ვიზუალურ ტექსტთან თანხვედრაში უნდა იყოს.

## კონტენტის შემდგომი ცვლილება

ჩაწერეთ მოთხოვნა, შესაცვლელი ტექსტი და წყარო; შეამოწმეთ ქართული მართლწერა, EN/RU მნიშვნელობა, მობილური გადატანა და რეალური მოქმედება. განხორციელების ფაქტი და მომხმარებლის მიერ საბოლოო მიღება ცალკე აღრიცხეთ [მიღების ჩანაწერში](IMPLEMENTATION_ACCEPTANCE.md).
